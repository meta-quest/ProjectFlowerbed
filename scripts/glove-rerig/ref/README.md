# Reference hand skeletons

`left.glb` and `right.glb` are the `generic-hand` models from
[`@webxr-input-profiles/assets`](https://github.com/immersive-web/webxr-input-profiles)
1.0.20, unmodified. `rerig.mjs` reads only their joint hierarchy to re-rig the
Flowerbed gardening gloves onto the WebXR hand skeleton.
